# Goddit - Reddit clone project

### For database diagrams and report: look in the `docs` folder!

### How to run:
- With `docker compose` simply have port 3307 and 27017 open and run `docker compose up` inside the project folder to start the db
- To also run the API, either run the `app` executable inside `/backend`, or run `go run .` inside the `/backend` directory.
